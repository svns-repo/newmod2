# Block ESP (Fabric, Minecraft 26.2)

Highlights chests, barrels, shulker boxes, ender chests, spawners and trial spawners through walls.
Toggle it with the "Toggle Chest/Spawner ESP" key under Options > Controls > Key Binds > Block ESP (default: X).

## Building
Every push runs GitHub Actions (`.github/workflows/build.yml`). Open the **Actions** tab, click the latest run,
and download **Artifacts**. Use the jar that does NOT end in `-sources.jar`.
